# PRD：智能视频粗剪助手（MVP）

> 版本：v2.2
> 状态：已实现，待真实素材验收
> 更新日期：2026-07-15
> 产品定位：macOS 本地优先的中文活动视频粗剪助手

## 1. 产品目标

用户导入一条带音频的中文活动视频，用自然语言描述目标，系统生成可预览、可确认的候选片段；用户保留需要的片段后，可选 BGM、转场与字幕样式，导出带中文字幕的 MP4 粗剪成片。

它解决“找素材、选素材、控时长、做字幕”的初稿工作，不替代专业剪辑软件或专业时间线。

## 2. 目标用户与场景

| 用户 | 使用场景 | 希望得到的结果 |
| --- | --- | --- |
| 学校宣传老师 | 运动会、典礼、演出回顾 | 重点覆盖开场、高潮、颁奖的可审核初稿 |
| 企业行政/市场 | 培训、活动、产品演示 | 能给领导审核的短视频初稿 |
| 内容编辑 | 活动报道配套视频 | 有字幕、信息连贯、可直接发布或微调的 MP4 |

典型输入：“剪成 5 分钟，突出开幕、冲刺和颁奖，正式一点。”

## 3. 已实现的 MVP 范围

### 3.1 输入、需求与预检

- 导入单个带音频的视频；FFmpeg 负责实际解码，常见 MP4、MOV、AVI、MKV 均可尝试处理。
- 预检视频流、音频流、时长和分辨率；无法解码或没有音频流时停止任务并提示错误。
- 支持自然语言需求，并提供可直接覆盖的结构化参数：目标时长（30–600 秒）、风格、重点关键词、中文字幕开关。
- 默认目标时长为 5 分钟；背景音乐默认关闭，MVP 不处理音乐文件或版权。

### 3.2 分析与人工确认

- Faster-Whisper 在本机生成带原始时间戳的中文转录。
- LLM 基于转录文本和需求生成候选高光片段；候选必须落在对应文本块的合法时间范围内。
- 候选按重要性筛选后按原片时间顺序排列；过短（少于 3 秒）或时间重叠的候选会被过滤。
- 用户在导出前勾选要保留的片段；没有用户确认，Web UI 不会渲染成片。
- 每个候选片段生成低分辨率可播放预览，预览失败不阻断生成方案。

### 3.3 字幕、导出与任务产物

- 仅为最终保留片段生成字幕，并将源视频时间戳重新映射为成片时间轴。
- 确认导出时，LLM 仅校对最终片段中字幕的错别字、同音字与断句；不改变时间轴、不扩写内容，调用失败时保留原 ASR 文本。
- 用户可上传 BGM；系统将其循环并以低音量混入原声。相邻片段可选 0–1 秒淡转场，提供经典、简洁、醒目三种字幕样式。
- 用户可分别选择无片头/片尾、2 秒标题卡或黑场淡入淡出；片头标题可自定义，片尾默认显示“感谢观看”。片头时字幕时间轴自动后移，二者均计入预计成片时长。
- 输出 H.264/AAC MP4；优先使用 macOS `h264_videotoolbox`，不可用时自动回退 `libx264`。
- 导出后校验文件存在、可解析、包含视频流且时长接近计划。
- 每个任务保存到 `output/tasks/<task_id>/`：媒体预检、需求、分析、剪辑计划、确认计划、SRT、渲染日志、执行结果与最终视频。

## 4. 用户流程

```text
上传视频
  → 填写需求与可选参数
  → 本地转录和文本分析
  → 勾选保留候选片段
  → 确认并导出
  → 预览 MP4、查看/复制 SRT
```

CLI 同样会在生成方案后列出候选片段，并要求输入保留的编号后才导出。

## 5. 验收标准

| 类别 | 当前验收方式 | 状态 |
| --- | --- | --- |
| 剪辑计划 | 候选筛选、去重、顺序与字幕重映射自动测试 | 已覆盖 |
| 媒体预检 | 自动生成含音视频的测试素材并读取元数据 | 已覆盖 |
| 渲染 | 裁剪、淡转场拼接、BGM 混音、字幕烧录、VideoToolbox 回退与输出校验 | 已覆盖 |
| 任务归档 | 方案、确认、导出后任务文件完整性 | 已覆盖 |

| 真实效果 | 运动会、会议、竞赛真实素材与用户评分 | 待验收 |

当前自动测试共 5 项。真实素材上的处理耗时、转录准确率、候选片段接受度和 API 成本需要在实际使用中记录，不在当前代码测试中承诺数值。

## 6. 产品边界与已知限制

- 输入必须有音频流；无声画面高光目前无法可靠识别。
- LLM 会接收用户需求和转录文本；原始音视频在本机处理。
- 任务产物会被保存，但当前版本**不提供中断后恢复或取消按钮**。
- 当前提供候选清单与预览确认，不提供拖拽时间线或逐字人工字幕校对。
- 不支持多素材、多机位、竖屏重构、封面、自动配乐、丰富转场模板和协作审批。

## 7. 后续版本

- **V1.1**：任务恢复/取消、转录与分析缓存、真实素材评测集。
- **V1.2**：基础视觉特征（场景切换、响度）、竖屏输出、封面和更丰富的 BGM/转场控制。
- **V2.0**：多素材项目、多语言字幕和更细粒度的编辑能力。
