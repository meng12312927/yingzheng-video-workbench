# 映证项目简历表述

以下内容可直接按简历篇幅删减。离线评测指标与真实用户指标必须分开描述，首轮 6 个真实任务完成前不要写“提升效率”或“减少返工”等未经验证的结论。

## 一句话项目介绍

映证是面向学校与企业活动视频的 AI 需求编译和证据审核工作台，将模糊剪辑要求转成版本化任务书，并通过可追溯证据、人工 Gate 和逐项验收生成可审核粗剪。

## 简历项目经历

- 设计多阶段 AI Harness，编排需求编译、动态澄清、素材—需求对齐、候选检索和字幕校对；限制 LLM 只生成建议，由状态机、版本控制和人工 Gate 决定任务书、计划与渲染是否生效。
- 实现 BM25 + Embedding/FAISS 混合检索与 RRF 融合，候选 Agent 仅能调用受限的 `search_evidence` / `expand_evidence` 工具；由代码补齐并校验证据 ID、原文引用、需求映射和时间边界，避免把模型自由文本当作证据。
- 构建按单项需求分批选片、局部重试和确定性合并流程，避免长上下文与结构化输出超限；支持多素材顺序合并、片段审核、人工补片、字幕/BGM/转场和 FFmpeg 导出，并保存模型调用与用户决策审计记录。
- 建立学校 3 项、企业 3 项的去标识离线回归集；当前 Recall@3、MRR、NDCG@3 均为 1.0，构造的错误引用可被校验层拒绝，校验后幻觉引用率为 0。另设计 6 个真实任务的验证协议，用于后续测量确认耗时、`must` 召回率和返工次数。

## 面试时主动说明的边界

- 离线 6 项评测验证的是检索和引用校验链路，不代表真实用户效率提升。
- MVP 的多素材能力是按上传顺序串接，不是多机位同步或自动择镜。
- 项目使用 Harness 控制流程，不宣称是可自由循环调用工具的通用 Agent；引入 LangGraph 要等真实多轮分支与恢复需求出现后再判断。
