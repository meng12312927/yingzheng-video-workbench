# 映证项目 21 天接管与 AI 应用开发实习冲刺计划

> 版本：v1.0  
> 制定日期：2026-07-17  
> 学习强度：每天 6–9 小时，共 21 天  
> 对应项目：映证｜活动视频需求与审核工作台

## 0. 先说明这份计划能做到什么

三周无法让一个初学者诚实地“精通全部 AI 技术”，也无法同时精通 Python、Java、Spring Cloud、Kubernetes、模型训练、多模态和所有向量数据库。

这份计划的现实目标是：

1. 真正接管映证项目的核心链路，不再只是运行 AI 生成的代码。
2. 达到 Python AI 应用开发实习生应具备的基础能力。
3. 能解释、修改、测试和排查映证，而不只是背 README。
4. 建立 LLM、RAG、Tool Calling、FSM、Memory、评测、存储和部署的完整知识地图。
5. 明确三周后仍需继续学习的 Java、云原生、微调和生产工程内容。

三周结束时，不应该说“我精通所有 AI 技术”，而应该能诚实地说：

> 我能独立解释和维护一个证据约束型 LLM 视频工作流，理解其需求编译、混合检索、工具调用、状态机、审核门禁、媒体执行、验收和评测链路；我能修改核心功能、补测试并排查常见错误。

## 1. 三周结业标准

只有同时达到以下标准，才算完成计划。

### 1.1 产品与架构

- 不看文档，能用 5 分钟讲清楚用户、痛点、核心流程和与剪映的差异。
- 能在白纸上画出从用户输入到 MP4 的完整数据流。
- 能解释 Harness、Compiler、Retriever、Analyzer、Gate、Planner、Renderer 和 Verification 的职责。
- 能说出当前产品边界、未实现方向和为什么不做全自动正式交付。

### 1.2 代码所有权

- 能沿主流程找到一次任务经过的主要函数。
- 能解释核心函数的输入、输出、主要步骤、调用对象和失败路径。
- 能解释至少 15 个核心 Pydantic 模型是谁生成、谁读取。
- 能独立完成一个小功能修改、一个 Bug 修复和对应测试。
- 能从任务目录恢复一次任务，并解释主要 JSON/JSONL 产物。

### 1.3 AI 应用知识

- 能解释 API、Token、上下文、Prompt、JSON Mode 和 Structured Output。
- 能解释 Embedding、BM25、向量检索、FAISS、RRF、Rerank 和 RAG。
- 能手画 Function Calling 循环。
- 能解释幻觉、引用校验、Prompt Injection 和输出合规。
- 能解释 Agent 与确定性 Workflow 的差异。
- 能解释 FSM、Event、Guard、幂等、ReviewGate 和 Memory 分层。

### 1.4 工程能力

- 会使用 Git 分支、diff、commit 和回退思路。
- 会运行 pytest，并能看懂一个失败测试。
- 会用日志和断点/打印定位错误。
- 理解 PostgreSQL、Redis、Docker、环境变量和健康检查的基本用途。
- 理解 vLLM、本地模型、量化、吞吐、TTFT 和 P95 的基本概念。

### 1.5 面试能力

- 能完成 15 分钟项目讲解。
- 能回答本计划末尾的核心面试题。
- 能诚实区分自己亲自完成、AI 辅助完成和仍未掌握的部分。
- 能现场完成一个 30–60 分钟的小修改或调试题。

## 2. 每天固定学习结构

每天按 8 小时标准安排。只有 6 小时时完成“必修”；有 9 小时时完成“加练”。

| 时间 | 内容 | 要求 |
| --- | --- | --- |
| 30 分钟 | 复习前一天 | 不看笔记复述，再检查遗漏 |
| 2 小时 | 项目代码主线 | 一次只读一个类或一组相关函数 |
| 1.5 小时 | 通用知识 | 学习当天对应的 AI/后端知识 |
| 1.5 小时 | 动手实验 | 运行、修改、写小程序或制造错误 |
| 1 小时 | 测试与排错 | 跑测试、读日志、验证假设 |
| 45 分钟 | 输出笔记 | 必须用自己的话，不复制代码注释 |
| 45 分钟 | 面试表达 | 录音回答当天问题 |
| 可选 1 小时 | 加练 | 完成扩展实验或补薄弱知识 |

如果当天只有 6 小时：

- 不取消动手和测试。
- 缩短阅读范围。
- 加练全部顺延。
- 不用“看完很多文件”替代“真正理解一个函数”。

## 3. 学习产物目录

建议在个人笔记工具或项目外的私人笔记中保存学习过程；不要把密钥、私人面试记录或大段复制代码提交到公开仓库。

每天至少产生：

```text
day-XX/
├── summary.md          # 今天学到什么
├── data-flow.md        # 输入、输出和调用关系
├── questions.md        # 仍然不懂的问题
├── interview.md        # 面试题的口头答案提纲
└── experiment.md       # 实验步骤、结果和错误
```

维护四本持续更新的账：

1. **术语账**：英文、中文含义、项目中的例子。
2. **数据账**：每个模型是谁创建、保存在哪里、谁读取。
3. **错误账**：错误现象、定位过程、根因、修复和防复发测试。
4. **决策账**：为什么采用当前方案、替代方案及权衡。

## 10. 每日学习协作方式

后续可以直接在对话中发送：

```text
开始第 1 天
```

每天教学严格按以下顺序：

1. 检查昨天是否真正掌握。
2. 讲当天一个模块，不一次倾倒大量代码。
3. 用中文伪代码解释“为什么、输入、输出、步骤、失败”。
4. 再看真实代码。
5. 做一个实验。
6. 做一个测试或修改。
