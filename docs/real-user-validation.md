# 映证真实用户验证方案

> 当前状态：等待授权素材与真实操作者。仓库已有学校 3 个、企业 3 个去标识离线评测任务，但它们只用于工程回归，不能冒充真实用户验证。

## 1. 验证批次

首轮固定为 6 个任务，每个任务必须来自一段或多段获授权的真实活动视频，并由实际负责剪辑或审核的人完成。

| 任务编号 | 场景 | 建议素材 | 操作者 | 状态 |
| --- | --- | --- | --- | --- |
| SCH-01 | 学校 | 运动会/校园活动 | 待提供 | 未开始 |
| SCH-02 | 学校 | 颁奖/知识竞赛 | 待提供 | 未开始 |
| SCH-03 | 学校 | 会议/访谈 | 待提供 | 未开始 |
| ENT-01 | 企业 | 发布会/年会 | 待提供 | 未开始 |
| ENT-02 | 企业 | 培训/会议 | 待提供 | 未开始 |
| ENT-03 | 企业 | 访谈/客户活动 | 待提供 | 未开始 |

原始视频、转录、人物名单和内部信息只保留在本地 `data/` 与 `output/`，不得提交 Git。提交仓库的只能是经操作者确认的聚合指标和去标识案例。

## 2. 每个任务开始前

操作者先在不看 AI 结果的情况下写下人工基准：

- 原始模糊需求和目标时长。
- 必须出现的环节、人物、奖项、产品或发言。
- 禁止出现的内容。
- 人名、职务、奖项等正确文本。
- 原流程从接收需求到首版成片的耗时。

## 3. 操作记录

每个任务记录以下字段：

| 字段 | 记录方式 |
| --- | --- |
| 任务书确认时间 | 从提交原始要求到确认任务书的审计时间 |
| AI 有效追问数 | 用户实际补充或明确忽略的问题数 |
| 重复追问数 | 已明确槽位再次被询问的次数 |
| `must` 总数/命中数 | 人工基准与候选审核结果对照 |
| 证据引用有效/无效数 | 确定性引用校验报告 |
| 方案审核时间 | 打开候选审核页到提交方案，不含观看素材时间 |
| 候选保留/删除/修改数 | 计划版本和审核事件 |
| 人工补片数 | `user_annotation` 证据数量 |
| 重新导出次数 | 渲染版本数量减一 |
| 主观结果 | 5 分问卷：是否比原流程更容易说清需求 |

## 4. 首轮通过线

- 任务书中位确认时间不超过 5 分钟。
- 平均有效追问不超过 3 个，重复追问率为 0。
- 人工基准中的 `must` 候选召回率至少 90%。
- 证据引用有效率至少 98%，校验后幻觉引用率为 0。
- 方案审核中位时间不超过 5 分钟。
- 每任务平均重新导出不超过 1 次。
