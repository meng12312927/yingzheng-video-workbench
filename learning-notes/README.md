# 映证学习笔记

这里保存 [21 天学习计划](../docs/learning-plan-21-days.md) 的每日学习产物。

## 目录规则

每天使用一个独立目录：

```text
day-XX/
├── summary.md
├── data-flow.md
├── questions.md
├── interview.md
└── experiment.md
```

五份文件分别记录：

- `summary.md`：用自己的话总结今天真正掌握的内容。
- `data-flow.md`：记录数据的输入、输出、修改者和读取者。
- `questions.md`：保存尚未理解、需要复习或需要验证的问题。
- `interview.md`：整理面试题答案提纲，并记录口头表达问题。
- `experiment.md`：记录命令、实验步骤、预期结果、实际结果和错误。

## 使用规则

1. 不要整段复制源码注释或 AI 回答。
2. 每个结论尽量附上对应文件或测试。
3. 实验失败也要记录，重点写清楚定位过程。
4. 不要记录 API Key、密码、Token 或私人数据。
5. 每天结束前完成“是否通过当天验收”的自评。
